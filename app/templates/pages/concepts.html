💡 Explanation of Concepts

Master core linear algebra concepts with clear definitions, mathematical formulas, and intuitive explanations.

Fundamental

Matrices & Operations

A matrix is a rectangular array of numbers arranged in rows and columns. Matrix multiplication requires the column count of \(A\) to equal the row count of \(B\).

Key Formulas:

(A × B)ij = ∑ Aik Bkj (AT)ij = Aji
Properties

Determinants & Inverses

The determinant measures the scaling factor of the transformation induced by a matrix. A matrix is invertible if and only if \(\det(A) \neq 0\).

Key Formulas:

det(A-1) = 1 / det(A) A-1 = (1 / det(A)) · adj(A)
Geometry

Vectors & Dot/Cross Products

Vectors represent quantities with magnitude and direction. Dot products measure alignment/projection, while cross products produce perpendicular vectors.

Key Formulas:

u · v = |u||v| cos(θ) |u × v| = |u||v| sin(θ)
Algebra

Linear Systems \(Ax = b\)

A linear system can have exactly one unique solution, infinitely many solutions, or no solution (inconsistent). Solved via Gaussian elimination to RREF.

Rouché-Capelli Theorem:

System is consistent if rank(A) = rank([A|b]). Unique if rank equals number of variables.
Advanced

Eigenvalues & Eigenvectors

Eigenvectors are non-zero vectors whose direction is unchanged by a transformation \(A\); they are scaled by eigenvalue \(\lambda\).

Characteristic Equation:

det(A - λI) = 0
Transformation

Linear Transformations

Functions between vector spaces that preserve vector addition and scalar multiplication: \(T(cu + v) = cT(u) + T(v)\).

Common 2D Matrices:

Rotation: \(\begin{bmatrix}\cos\theta & -\sin\theta \\ \sin\theta & \cos\theta\end{bmatrix}\)
