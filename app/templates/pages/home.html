Quick Reference

Matrix Operations
  • Addition / Subtraction — same dimensions required
  • Multiplication — A(m×k) × B(k×n) = C(m×n)
  • Inverse — exists only if det(A) ≠ 0
  • Transpose — flip rows and columns
Vector Formulas
  • Magnitude — |v| = √(x² + y² + z²)
  • Dot product — a · b = |a||b|cos(θ)
  • Cross product — 3D vectors only, result is ⊥ both
  • Projection — proj_b(a) = (a·b / |b|²) b
